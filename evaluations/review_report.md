# Claim Verifier 标注规约与 32 条候选复核报告

2026-10-24。此报告由 Agent 基于项目本地**实际传入的证据**编制，属于待独立人工复核的工作底稿；**没有医学专家验证**，也未重新验证 WHO/CDC 网页的医学事实和现行性。本轮未调用 Ollama、未修改原始标签、V1/V2 Prompt、生产 Agent、FastAPI 或历史实验结果。

## 交付内容

- `evaluations/annotation_guidelines.md`：四分类项目规约，含判断顺序、数字/量词、人群、疗效、显式歧义与反例；明确它不是唯一正确的通用事实核查标准。
- `evaluations/review_checklist.csv`：原始 24 条 + 保留 8 条共 32 行。每行含案例 ID、主张、实际传入的逐字证据、原始标签及理由、Agent 建议标签及理由、争议说明，并留空人工最终标签和人工复核意见。
- `evaluations/explanation_fidelity.md`：将分类一致、引用有效、解释忠实度分别定义；解释忠实度需人工逐条核对命题与原文。
- `evaluations/explanation_fidelity_review.csv`：从已经保存的 8 条 V1/V2 配对真实评测中整理 16 条理由的人工审核队列。自动规则只给候选提示，人工忠实度栏为空。
- `evaluations/review_checks.py`、`evaluations/explanation_fidelity.py` 及离线测试：验证清单来源、字段、证据原文、人工栏状态和候选提示；不连接模型。

## 32 条建议与争议

按照新规约逐条提出的 32 个建议标签与原始初标**相同**。这表示当前文本规约下尚未找到必须立即改标的条目，**不表示独立人工已经认可标签**；清单中的所有 32 个“人工最终标签”都仍为空。

清单将 **12 条**标为需优先讨论的争议或解释问题：

| 优先案例 | 需要人工裁决的边界 |
|---|---|
| U001、U002、H-U01 | 明确列出待选版本、最终版未定：按本项目规约建议 `uncertain`，但与普通“缺少最终信息→not_supported”存在标注约定之争。 |
| U003 | “他们”可能指 A 组或 B 组：是否足以把关于 A 组的断言标 `uncertain`。 |
| U004 | 量词明确可能是全部或部分：不能把“可能全部”当作已支持“所有”。 |
| U005 | 表中 7 小时可能是建议值或观测均值：需确认数据性质的未决解释。 |
| U006 | “和”明确可能是两项同时满足或任一满足：需确认逻辑关系的未决解释。 |
| H-U02 | 20% 分母明确可能为全体或甲组，但自然阅读可能默认全体。 |
| N001 | “至少 7 小时”不能推出“必须 12 小时”，也不直接排除 12 小时；建议 `not_supported`。 |
| C002 | “15–30 分钟，而不是 150–300 分钟”是否按同一推荐口径构成明确替换冲突；建议 `contradicted`。 |
| H-C01 | “建议少于 7 小时，而不是至少 7 小时”在**推荐**口径下互斥；建议 `contradicted`。 |
| H-N02 | 建议标签 `not_supported` 基本清楚，争议在既有 V2 理由把训练建议额外说成“对成年人有益”；须单独审解释忠实度。 |

其余 20 条目前无明显语义边界争议，但**仍须人工最终确认**。合成歧义案例只为测试语言规则，不是医学建议。若人工认为项目规约本身需改变，应先记录规约版本与理由，再发布新的标签版本；不能覆盖原 24 条、8 条保留集或历史结果。

## 解释忠实度：现有结果的具体待查点

已有 8 条配对实验的 V1/V2 分类一致率均为 75%，`uncertain` Recall 均为 0/2；引用有效率分别为 4/4、5/5。这些是**对待复核初标的一致情况**。解释忠实度尚未被人工打分，不能给出百分比。

离线提示队列为 16 条历史理由生成 **2 条候选提醒**，不是 2 个已确认错误：

1. **H-N02 / V2**：理由中说原证据表明力量训练“对成年人有益”；实际传入事实只写“每周还应安排至少 2 天涉及主要肌群的肌肉力量训练”。需人工判断“有益”是否构成无依据新增效果。分类仍与初标一致，且没有非空引用；这些指标不能替代解释审核。
2. **H-S01 / V1**：理由出现“1.50分钟”，而输入为“75至150分钟”。需人工核对这是生成文本中的数字变形、笔误，还是影响解释的错误。

候选检测仅对少量效果词和带单位数字做文本比对，可能漏报同义新增，也可能误报正常推理；**不自动判不忠实、不计算解释忠实度分数**。人工应将理由拆为最小事实命题，逐个定位到输入事实，并区分“转述待核查主张”和“声称证据已经证明”。
