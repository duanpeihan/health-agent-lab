# 解释忠实度检查设计（离线人工审核）

## 三个互相独立的指标

| 指标 | 问题 | 判定与分母 |
|---|---|---|
| 分类一致率 | `verdict` 是否与**指定版本的人类最终标签**一致？ | 正确条数 / 全部案例；当前标签未最终复核，只能报告“与初标一致率”。 |
| 引用有效率 | 非空引用的编号、文档和逐字原文是否真的来自本次输入？ | 有效非空引用 / 全部非空引用；另报该引用的要求满足率。空引用不计入前一分母。有效引用不保证它支持结论。 |
| 解释忠实度 | 理由中的每个**作为事实陈述**的主张，是否受输入证据支持、准确描述缺证据或冲突关系，且未添加新的医学/因果事实？ | 需人工逐条审核；忠实案例 / 已完成人工审核的理由。未审核不得填 0 或 100%。 |

这三个指标可以分别失败：H-U02 的 V2 引用来自输入原文，但分类与初标不一致；H-N02 的 V2 分类与初标一致、没有假引文，理由却称原证据说明训练“对成年人有益”，而实际输入只给出建议频率。**分类对、引用真，都不自动意味着解释忠实。**

## 人工审核流程

1. 展示一条案例的主张、实际传入的所有 `facts`、模型理由、最终标签和模型引用。先确认理由是在**引用来源事实**、**转述待核查主张**，还是在陈述模型自己的推理。转述错误主张只要明确写“主张称……”，不当作模型认可该事实。
2. 将理由拆成最小可检验命题，尤其标出来源归属（“证据指出……”）、数字/量词、人群、建议与观察、疗效、因果、确定性词语。为每个来源事实命题标出支持它的输入事实原句；无法标出的命题列为候选问题。
3. 检查引用是否与被引用的命题相关。引用逐字存在只是“有效”；若原文没说出理由里的额外效果，解释仍不忠实。
4. 对理由整体判 `忠实`、`存在无依据新增事实`、`错误转述或夸大证据`、`无法裁定`，并记录问题片段、对应原文和判断依据。可同时记录多个问题。模型只是明确说“证据未提到 X”时，X 可来自待核查主张，不应误判为新增事实。
5. 由独立审核者填写最终结果；争议条目二次审核。任何自动规则只产生**待查候选**，不能充当人工解释忠实度分数。

## 离线候选提示

`explanation_fidelity.py` 从既有真实报告生成 16 条 V1/V2 理由的人工审核队列。它只查找理由中出现、但在主张与输入证据原文中均未出现的少数效果词和带单位数字，记录为 `候选新增内容`。例如 H-N02 V2 的“有益”会被提示。该方法会漏掉同义改写的事实添加，也可能误报正常推理；**不输出忠实度分数，不调用 Ollama，不改历史报告**。

人工审核建议先看：H-N02 的效果词、H-U01 的无关“扩大人群/疗效”模板化理由、H-U02 的“分母不明确”却判 `not_supported`，以及历史 C002 数字区间理由。分类边界争议与解释问题应分开记录；先确定标签版本，再统计最终分类一致率。
