# 最终 Reflection ON/OFF 配对 A/B：公开摘要

这是已冻结实验的脱敏公开投影，不是新增实验或重评分。四个场景、八次独立端到端评测图运行，复用生产节点和路由。OFF仅关闭自动重写，ON最多修正一次；两组保留相同的医学证据、数字、任务参数与发布门禁。

| 指标 | OFF | ON |
|---|---:|---:|
| 完成并通过程序发布门禁 | 0/4 | 2/4 |
| 含R-NONE正确停止的程序目标达成 | 1/4 | 3/4 |
| 安全停止 | 4/4 | 2/4 |
| 可观测门禁违规发布 | 0 | 0 |
| Reflection修正成功 | 不适用 | 2/3 |
| 模型调用 | 7 | 12 |
| Writer耗时合计 | 9.97秒 | 16.61秒 |
| Verifier/Checker耗时合计 | 11.20秒 | 13.93秒 |
| 任务耗时合计 | 21.20秒 | 30.59秒 |
| P50/P95 | 6.69/7.74秒 | 9.16/12.23秒 |

ON在本轮救回R-NORMAL和R-INJECT，多5次模型调用、9.3865秒任务耗时（+44.3%）。R-INSUFFICIENT修正后仍将20分钟复述为2.0分钟，被任务参数门禁拦截；R-NONE两组均零模型调用停止。安全停止率的差别来自两项任务被修复完成。

程序completed不等于独立医学正确或完整任务质量合格；独立人工审核尚未完成，相关成功率未知。可观测违规发布为0不代表未发现的医学错误为0。

每组仅4个样本，含零模型任务；P50/P95采用(n-1)*p线性插值，仅作描述。OFF首个Writer包含约2.075秒模型加载，未事后扣除。固定AB/BA顺序仍受缓存及负载影响，不能把本轮耗时差推广为稳定开销，也没有显著性结论。

Writer为qwen3:4b、json_article_v1、think=False、temperature=0、seed=42、num_predict=512、num_ctx=4096、45秒请求超时；Verifier读取生产实际配置，仅temperature=0，未被旧脚本覆盖。实验冻结时457项离线测试通过，无真实任务重跑、超时或截断。Git HEAD之外另有源码SHA，因为实验时工作区已有未提交改动。
